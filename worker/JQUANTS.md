# Works MCP の J-Quants 接続

既存の `/mcp` と所有者用 OAuth 認証に、読み取り専用の3ツールを追加します。

| ツール | 用途 |
|---|---|
| `search_stock_symbols` | 最新上場銘柄一覧の企業名・証券コード検索 |
| `get_latest_stock_price` | 直近30暦日の最新非欠損終値と実際の取引日 |
| `get_stock_price_history` | 銘柄・期間指定の日次四本値、通常終値・調整済み終値 |

## 接続手順

1. Cloudflare の Workers & Pages → `works` → Settings → Variables and Secrets で、**Secret** 型の `JQUANTS_API_KEY` にJ-Quants V2のAPIキーを設定します。既存のシークレットは保持してください。APIキーをGitHub・PR・チャットへ記載しないでください。
2. この変更を既存のWorks Workerのデプロイ手順で反映します。CLIの場合は `worker` ディレクトリで `npm ci`、`npm run deploy` を実行します。
3. ChatGPT側の既存Works接続でツール一覧を更新します。新しい3ツールが出ない場合はWorksを再接続します。接続先は既存の `https://works.lrnr.jp/mcp` です。
4. `get_latest_stock_price` に `{"code":"7203"}` を渡し、出典・実際の取引日・終値を確認します。実APIの検証にはシークレット設定と本番反映が必要です。

認可画面には株価取得が含まれることも表示します。既存の個人用 `schedule:read` 接続権限を使用し、新たな公開APIや認証の迂回経路は追加しません。

## データの扱い

- `close` は当日の調整前終値、`adjusted_close` は分割等調整済み終値です。現金配当調整は含まれません。
- `null` は欠損として維持し、0や前日の価格で補完しません。
- 直近終値では当日値と断定せず、常に `data.date` を併記してください。30日間に値がない場合は `data: null` と検索期間を返します。
- 履歴は日付昇順です。全ページを取得し、ページ上限や不整合ではエラーを返します。部分取得を完全な結果として返しません。
- 取得は最大1830日、実際の利用可能期間はJ-Quants契約に従います。Lightは過去5年です。要求期間と実際の取得期間を別々に返します。
- 最新上場銘柄一覧の検索は、過去の上場廃止銘柄の網羅検索ではありません。
- 本機能は認証済み所有者の個人利用向けです。APIキーは固定のJ-Quants V2ホストにのみ送信します。上流エラー本文や例外内容を回答に転送しません。

## 検証

`node --test test/jquants.test.mjs`

認証なしの拒否、引数検証、ページング、銘柄照合、通常値・調整値・欠損、直近取引日の扱い、上流エラーとキー非露出をモックで検証します。実データ取得を検証したものではありません。

仕様: https://jpx-jquants.com/ja/spec/eq-bars-daily

## 通信エラーの切り分け

エラー本文の固定コードで分類できます。例外本文・スタック・応答本文・リダイレクト先・APIキーは返しません。

| コード | 意味 |
|---|---|
| JQ_KEY_FORMAT | Secretに空白・改行・非ASCII文字などがある |
| JQ_TIMEOUT | 接続が15秒以内に完了しなかった |
| JQ_ABORTED | 通信が中断された |
| JQ_FETCH_TYPE | 構築または通信時のTypeError。根本原因は未確定 |
| JQ_NETWORK | その他の通信例外。DNS/TLSなどの断定は不可 |
| JQ_REDIRECT | 3xx応答。APIキー保護のため追従しない |
| JQ_HTTP_401 / 403 / 429等 | 上流から受信したHTTPステータス |

本番反映後に同じ銘柄を再取得し、返ったコードで次の調査を行います。モックテストの成功は、本番接続の復旧を意味しません。
