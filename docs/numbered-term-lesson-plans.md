# 学期の回数別授業予定

授業管理の設定で学期の期間と対象カレンダーを選び、「回数別の授業予定」を有効にします。「冬期／冬季」を含む学期では既定で有効です。他の学期の既定動作は変わりません。

- 授業記録カードと生徒情報のカリキュラムは、対象カレンダーの学期初日から、同じ名前の授業を日本時間の開始順に数えます。別カレンダー、休講・不参加、空き枠、終日、管理予定は混ぜません。学期内で同名予定が重複している場合は推測で割り当てません。
- 「次回授業予定」に書いた内容は、その学期の次の回に保存されます。次のコマが未入力でも、現在の最後の授業カードから「日程未定」の次回を書けます。後で予定が追加されると、その回の欄に表示します。次の学期に自動で持ち越しません。
- 保存キーは学期ID・カレンダー・正規化した予定名・回数です。予定を動かす、削除して作り直す、間に追加するなどの操作で回数を再計算します。予定そのもの、実施記録、宿題、確認テスト、生徒メモは書き換えません。旧方式で書いた内容は元の予定に残り、カードでは「以前の予定別の記録」で読み返せます。既存内容の自動移行はしません。
- 読み込みに失敗した場合、以前の方式へ書き戻しません。別画面から先に同じ回を保存した場合、入力と保存済み内容を比較でき、本人の操作があるまで上書きしません。
- 今回の表示範囲は授業管理の記録カード・生徒情報です。カレンダーと授業通知の内容はこの変更では更新しません。

Worker の API は既存の D1 に加法的な専用テーブルを初回利用時に作ります。バインディング変更や既存テーブルのデータ移行は不要です。Pagesだけが先に配信された場合、読み込みエラーとして編集を止め、既存の記録には書き込みません。ロールバックで旧画面に戻しても、回数別の内容はD1に残ります。
