# Shared sidebar and user logo

The PC and mobile full menu is one DOM sidebar and one item registry. At 1024px and wider, Framework7 keeps the sidebar visible and the hamburger/close buttons are hidden. Below 1024px, the hamburger opens that same left cover panel. The five bottom shortcuts remain Home / Lessons / Materials / TODO / Memo; current URL drives selection in both locations. The former centered dialog and its duplicated menu markup are removed.

`sidebar-controller.mjs` coordinates Framework7 panel open/closed/breakpoint events with focus and scroll state. Mobile open makes the view and bottom navigation inert and aria-hidden, traps Tab/Shift+Tab inside the sidebar, and blocks background wheel/touch scrolling. Escape, close button and backdrop dismiss it and restore focus to a visible current-page opener. Successful routing closes without restoring an obsolete opener; rejected unsaved routing keeps the drawer/draft. Same-route links close the drawer. Sign-out removes locks before hiding private UI.

Breakpoint transitions close mobile state without animation, restore prior overflow/inert/aria-hidden values, remove stale backdrop/panel classes and leave the desktop sidebar available. Shrinking from desktop returns focus from a now-hidden sidebar to the current hamburger. Reduced motion is respected; Framework7 handles normal panel transitions. Drawer content scrolls independently, includes safe-area bottom padding, and exposes all ten menu items plus original-home access.

The user-upload commit `ded8ee8e416c31647248b14af2678853bead71f3` contained only root `logo.png` and was cherry-picked with provenance. No obsolete default-branch application code was merged. The root PNG is imported directly, remains byte-identical (SHA256 `d2b96812c576c2e13a0f8eac20e5515fec7c23fda3a4fc0ed79df031cc7be274`), and has no generated replacement or pixel edits. Desktop shows the square at 160px; mobile at 88px; tablet at72px. The original opaque white background remains visible in dark mode. Existing `shared/logo.png` is untouched.
