Cyclic/missing parents are repaired only for navigation; stored parents never change from reading. Create/rename/move folder, choose parent, exclude self/descendants, source and destination revisions; original has no folder-delete control. Folder dialog Enter/submit, cancel/Escape, dirty guard and focus recovery.
- Page list with30-item pagination, folder filter, archived visibility and global title/body/tag/alias search; clear search returns to folder. New page in explicit current folder with frozen folder revision; title/body/tags/aliases/related-page IDs/status/source fields. Related pages remain stable IDs. Create/edit/move/archive (explicit confirmation); original has no permanent page-delete control. Archive recovery is through explicit historical restore when applicable, not a new delete/unarchive shortcut.
- Editor edit/Markdown-preview switch, all six source types (onedrive/exam/vocab/works/web/other), ID or safe URL, location and checked date, add/remove source. Confirmed status requires sources. Original explicit Save and separate Save Proposal remain distinct; no blur autosave is added.
- Reading: safe Markdown, headings/outline, tables/lists/quotes/code/HTTP(S) links; external images and raw HTML are escaped/sanitized with existing pinned renderer. Reading focus toggle, related-page links, source metadata and current revision/status. Content, proposals and history are separate keyboard-accessible tabs.
- Proposal notes, original base revision, pending/accepted/rejected states; proposal creation never changes accepted body and server forces proposed content to draft. Compare lines and every source/state/folder/archive/tag/alias/link field. Adoption requires an explicitly opened review bound to exact page/revision/proposal/content, followed by an explicit user confirmation; embedded text is never approval. Rejection retains its separate explicit confirmation and server preconditions.
- History loads100 at a time, compare old/current, explicit restore as a new revision with immutable history; no snapshot deletion or arbitrary overwrite. Markdown and full JSON exports use existing server endpoints and authenticated session transport. Existing export size limits remain server-controlled.

## Native adaptation and guards

Original `/wiki/?folder=...&page=...` remains untouched; native `/app/#!/wiki/?folder=...` and `/app/#!/wiki/:id/?folder=...` plus bounded `page` compatibility query preserve URL/reload/Back/Forward. Framework7 remains the sole router. Same-document tree mode/expanded branches/search/archive/focus and action-selected proposal tab follow native transitions through private session state, cleared on auth invalidation.

Mutations are single-flight and retain frozen source/destination revisions. Acknowledgements must match target, version and mutation semantics. Conflict/unknown/bad acknowledgements stop writes without replay; a known successful write followed by a failed refresh also requires reconciliation. Saved/attempt/editor/folder/review snapshots can be exported. Inspection is read-only and never adopts by title or upgrades permission. Explicit discard/reset requires successful fresh reads before clearing protected input; creation/proposal requests with unknown server-generated IDs are not retried automatically. Known400/413 validation rejections allow explicit correction. Reading exports are fenced through session expiry, including the Blob read.

Original pinned marked and DOMPurify files/licenses are reused unchanged; license text also ships with built assets. Source/folder/review code is scoped to the module, without global handlers or duplicate auth initialization. Controls remain disabled during route handoff; rendered Markdown task checkboxes stay read-only. Unsafe legacy source URLs are preserved as escaped text rather than clickable execution targets.
